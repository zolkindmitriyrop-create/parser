# 📇 Company Parser — Парсер контактов компаний

Streamlit-приложение для сбора контактных данных компаний (телефон, email, адрес, руководитель) по ИНН / ОГРН из открытых источников.

## 🚀 Быстрый старт

### 1. Клонирование
```bash
git clone https://github.com/ВАШ_АККАУНТ/company-parser.git
cd company-parser
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## 📋 Как пользоваться

1. **Ввод вручную** — вставьте список ИНН, по одному на строку.
2. **Или загрузите Excel/CSV** — выберите файл с колонкой ИНН.
3. Нажмите **"Начать сбор"**.
4. Получите таблицу с результатами и скачайте Excel.

## ⚙️ Настройки

В боковой панели можно настроить:
- **Задержку между запросами** — чтобы не получить бан от сайтов.
- **Количество потоков** — параллельных запросов.

## 🌐 Источники данных

- [checko.com](https://checko.com)
- [list-org.com](https://list-org.com)
- [zachestnyibiznes.ru](https://zachestnyibiznes.ru)
- [audit-it.ru](https://audit-it.ru)

## ⚠️ Важно

- Данные собираются из **открытых источников**.
- Актуальность **не гарантируется** — используйте для предварительной проверки.
- Некоторые сайты могут блокировать автоматические запросы. В таком случае увеличьте задержку.
- Для промышленного использования рекомендуется подключение к платным API (Контур.Фокус, СПАРК и т.д.).

## 🚀 Деплой

### Вариант 1 — Streamlit Cloud (рекомендуется, бесплатно)
1. Залейте репозиторий на GitHub.
2. Перейдите на [share.streamlit.io](https://share.streamlit.io).
3. Выберите свой репозиторий → ветку `main` → файл `app.py`.
4. Готово! Приложение будет доступно по публичной ссылке.

### Вариант 2 — Render / Railway / Heroku
1. Залейте репозиторий на GitHub.
2. При создании сервиса выберите **Python**.
3. Укажите команду запуска:
   ```bash
   sh setup.sh && streamlit run app.py --server.port $PORT --server.address 0.0.0.0
   ```
4. Для Heroku используйте `Procfile` (уже в репозитории).

### Вариант 3 — Локальный запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```
